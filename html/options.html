Extra times of day

Optional: give a theme its own window during the day or the night (for example an “evening” theme from 21:00, or a “morning” theme from 06:00).

Rotate through several themes optional

Tick themes below to have automaticDark pick among them, instead of always using the same one. Useful with the day/night switch.

hours 0 = only when the theme switches.

Web page colour scheme

Tells websites whether to render light or dark (the same setting as “Website appearance” in Firefox's settings).

“Match the theme” follows the theme slot (light by day, dark at night).

Per-site overrides optional

One site per line: example.com dark or example.com light. Sub-domains are included. Lines starting with # are ignored.

Behaviour

Helps when another add-on or a manual change left the wrong theme on screen.

Custom themes advanced

Paste a theme object as accepted by browser.theme.update() — for example the JSON exported by Firefox Color. Select it as daytime/nighttime theme to use it.
